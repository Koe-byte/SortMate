# Evaluation run card

Open [[EVALUATION]] for thresholds, commands, field protocols and verification results. Use a debug APK, two distinct cloud members and a fresh run directory. For OCR, collect 20 receipts; for battery, book an uninterrupted four-hour interval.

The five header-only CSVs under `evaluation/` are templates. `score.ps1` will report `PENDING` until measurements exist. Keep synthetic scorer checks and indoor presence demonstrations out of field runs.
